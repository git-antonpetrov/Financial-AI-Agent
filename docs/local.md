# Локальный запуск

Настоящий документ описывает запуск стека на рабочей машине через Docker Compose. Скрипт `scripts/deploy_vds_prod.sh` для этого не используется: он требует открытый LUKS и каталог проекта на том же томе.

Локальный диск не шифруется LUKS. Конвертное шифрование в приложении и TLS между контейнерами при этом остаются включёнными.

---

## 1. Что нужно заранее

На машине должны быть Docker и Docker Compose v2. Файл `.env` создаётся из примера и заполняется скриптом секретов. Этот скрипт не открывает диск и не запускает контейнеры.

```bash
copy .env.example .env
python scripts/setup_vds_security_env.py
```

На Windows путь к интерпретатору может быть `py -3.11`. Скрипт пишет `.env` с режимом `0600` и первичный пароль администратора в `.secrets/initial_admin_password`. Оба пути перечислены в `.gitignore`.

Для вызовов моделей положите ключ учётной записи GCP в `data/gcp-service-account.json`. Без файла контейнеры поднимутся, но обращения к Vertex AI завершатся ошибкой. Каталог `data/` в git не входит.

`docker compose` не стартует, если в `.env` пустой `PROXY_INTERNAL_SECRET`. Скрипт выше заполняет его сам.

---

## 2. Запуск

Из корня репозитория:

```bash
docker compose up -d --build
```

Порядок задаёт сам Compose. Сначала один раз отрабатывает `root-ca` и выпускает сертификаты в тома. Затем поднимаются PostgreSQL, Redis, MinIO, ChromaDB, административный сервер, воркеры, шлюз симуляции и Caddy.

На хост публикуются только порты `80` и `443`. Базы и внутренние API с машины напрямую не открыты. Проверка живости Caddy с хоста на `http://127.0.0.1/health` не является контрактом: обработчик `/health` слушает этот адрес внутри контейнера.

Полезные команды:

```bash
docker compose ps
docker compose logs -f admin-server caddy
docker compose down
```

`docker compose down` останавливает контейнеры и не удаляет тома. Секреты в `.env` сохраняются.

---

## 3. Профили, которые сами не стартуют

| Профиль | Сервис | Когда нужен |
| --- | --- | --- |
| `seed` | `simulations-seeder` | Первичное наполнение учебных баз банка, инвестиций и цифрового рубля |
| `tools` | `pgadmin` | Просмотр PostgreSQL. В обычный контур не входит |

```bash
docker compose --profile seed up simulations-seeder
docker compose --profile tools up -d pgadmin
```

Шлюзы Cloudflare в `src/gateways` этим файлом Compose не выкладываются. Пока `VERTEX_BASE_URL` и `TAVILY_BASE_URL` указывают на заглушки из примера, модели и поиск с локального стека не заработают.
