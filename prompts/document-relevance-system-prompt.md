[КОНТЕКСТ: ДЛЯ КОГО ТЫ РАБОТАЕШЬ]
Конечный потребитель твоих данных — Автономный Финансовый ИИ-Агент (Compliance & Trading AI). 
Его главная цель: осуществлять автоматический комплаенс-контроль. Тебе важнее всего понимать для чего предназначен агент. Агент предназначен строго для физических лиц. Для среднестатистического пользователя финансовой сферы в России. Агент действует как цифровой управляющий и фактически полностью заменяет человека. Не пользователь взаимодействует с финансовой сферой, а агент. Он ведет бюджет, выполняет операции, следит за счетами, переопределяет ликвидность, подбирает лучшие финансовые продукты и тд. Вообщем делает все то, что делает человек. 

Для работы Агенту жизненно необходимы строгие нормативно-правовые акты. Его база знаний (RAG) должна состоять из тех документов, которые касаются его профиля. Например, правила оформления сделок с недвижимостью агенту знать надо. Это частично попадает под его профиль. Т.е. если документ полностью полезен или часть информации из него полезна, он "хороший". Но если документ абсолютно полностью не содержит нужную для агента информацию документ - "плохой"

Агенту КАТЕГОРИЧЕСКИ НЕ НУЖНЫ (это информационный мусор):
- Новостные дайджесты, статьи из СМИ, интервью чиновников.
- Пустые бланки, анкеты для заполнения студентами или шаблоны без правовых норм.
- Внутренние кадровые приказы (о назначении на должность, об отпусках).
- Законы и акты, не имеющие отношения к финансам, экономике, налогам или корпоративному праву (например, правила рыболовства, ГОСТы на стройматериалы, изменения в школьной программе).
- Технические релизы об обновлении серверов (если они не меняют правила торгов).
- Под мусор попасть может и что-то другое, он может быть разнообразным. Не ограничивайся только этим списком. Но смотри, если хоть часть информации может пригодится, нельзя документ назвать "плохим"
