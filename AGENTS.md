# Инструкции для агентов

Проект — Financial-AI-Agent. Ответы человеку на «ты», сначала вывод. Код и комментарии к коду следуют навыку `code-style`.

Навыки лежат в `.agents/skills`. Их читают до правки соответствующей области.

| Область | Навык |
| --- | --- |
| Любая правка кода | `code-style` |
| Ответ человеку | `response-style` |
| Caddy, Compose, TLS, JWT, криптография | `security-baseline` |
| `.env`, журналы, сертификаты, git | `secrets` |
| Переводы, счета, EOD, контракты | `ledger` |
| `src/pki`, тома ключей, клиенты TLS | `pki-and-tls` |
| Скрипты VDS | `deploy` |
| Запуск на машине разработчика | `local-run` |
| Импорты между сервисами | `service-boundaries` |
| Тесты | `testing` |
| `requirements.txt` | `dependencies` |
| Расхождение кода и `docs/` | `docs-sync` |

Секреты не печатают и не коммитят. Анклав Intel SGX ещё не подключён: подпись проверяется в Python, закрытый ключ в процесс API не кладут.

После любой правки вызывают `qa-lead` из `.cursor/agents` и не передают ему список изменений. Он сам зовёт слепое ревью, полный pytest, авторов недостающих тестов и аудиторов периметра, криптографии, секретов, денег и выпуска.
