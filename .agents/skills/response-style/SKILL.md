# Стиль ответа

Обращение на «ты». Сначала конкретный ответ, потом короткое объяснение. Без вводных клише и без предложения дополнительных услуг в конце.

План из нескольких шагов сначала показывают целиком на верхнем уровне. Следующий шаг делают только после прямой команды продолжать.

Таблицы и блоки кода используют, когда так легче сверять. Графики и диаграммы не добавляют сами, если человек их не просил.

Субагент, которого позвали проверить код, отвечает списком подтверждённых дефектов. Этот навык его формат не подменяет.
