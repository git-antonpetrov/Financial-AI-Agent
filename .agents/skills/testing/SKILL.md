# Тесты

Тесты лежат в `tests/`. Запуск из корня: `pytest`. Кэш пишется в `.cache/pytest`, не в корень.

Предупреждения, кроме перечисленных в `pytest.ini`, считаются ошибкой. Новый тест не глушит предупреждение, чтобы скрыть дефект.

Денежный сценарий проверяет повтор того же ключа идемпотентности и отказ при недостатке средств. Криптографический сценарий проверяет и успех, и подделку подписи или сертификата.

`FINANCIAL_AI_ALLOW_TEST_BRIDGES` включают только внутри теста и не оставляют включённым в `.env`. Настоящие секреты из `.env` в тест не подставляют.

После изменения поведения обновляют существующий тест этого поведения, а не добавляют второй, который проверяет то же самое другими словами.
