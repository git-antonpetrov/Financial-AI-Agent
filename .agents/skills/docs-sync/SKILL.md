# Документация

Короткие документы лежат в `docs/`. Оглавление — `docs/README.md`.

| Что изменилось | Какой файл править |
| --- | --- |
| Сети, порты, протоколы | `docs/security/network.md` |
| PKI, TLS, данные в покое | `docs/security/pki.md`, часть I и II |
| Скрипты VDS и Action | `docs/deploy/vds.md` |
| Локальный Compose | `docs/local.md` |
| Переменные `.env.example` | `docs/env.md` |
| Новые каталоги `src` | `docs/src.md` |
| Навыки или субагенты | `docs/agents.md` и `AGENTS.md` |

Часть III `docs/security/pki.md` не переписывают под текущий `root-ca`, если задача не в этом. Там целевая модель HSM и аппаратного анклава. В начале части уже сказано, что код выпускает сертификаты иначе.

Секреты и примеры настоящих ключей в документы не вставляют.
