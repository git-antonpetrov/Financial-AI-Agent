# Секреты

В git не попадают `.env`, `.secrets/`, `data/`, `certs/`, `*.pem`, `*.key`, `admin_2fa_qr.html` и каталог `.cache/`.

Парольная фраза LUKS никуда не записывается. Первичный пароль администратора пишется только в `.secrets/initial_admin_password` и не печатается в stdout. Скрипты выпуска и GitHub Action не выводят значения секретов.

Ключ GCP лежит в `data/gcp-service-account.json` с режимом `0600`. `.env` тоже `0600`.

Плейсхолдеры из `.env.example` в боевом файле недопустимы. `scripts/setup_vds_security_env.py` заменяет известные плейсхолдеры и не трогает уже случайные значения.

QR-код 2FA сохраняют только вне репозитория или в `.secrets`. HTML внутри отслеживаемого дерева `scripts/setup_2fa.py` отклоняет.

В тестах используют временные каталоги и фиктивные ключи. Настоящий `.env` в тест не читают и в утверждения не вставляют.
