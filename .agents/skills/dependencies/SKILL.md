# Зависимости

У каждой прямой библиотеки одна версия во всех `requirements.txt`. Корневой файл содержит объединение зависимостей сервисов и `scripts/host-requirements.txt`.

Образ сервиса ставит свой файл, не корневой. Хостовый выпуск ставит только `scripts/host-requirements.txt`: `cryptography` и `bcrypt`.

`chromadb` остаётся той же версии, что образ в `docker-compose.yml`. `litellm` держит точный `pydantic`, который объявляет сам пакет. Версию pydantic не поднимают отдельно от него.

Новую библиотеку добавляют в файл того сервиса, который её импортирует, и той же строкой в корень. Транзитивные зависимости в эти файлы не замораживают.
